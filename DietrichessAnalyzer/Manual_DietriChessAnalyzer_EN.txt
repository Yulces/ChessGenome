1. INTRODUCTION
-------------------------------------------------------------------------------

1.1 What is DietriChessAnalyzer?
--------------------------------

DietriChessAnalyzer is a chess analysis software that uses the Gödelian
representation of positions to quantify each position into a single unique
number called the S VALUE (S Value).

This representation converts any chess position into a unique natural number,
enabling:

  • Mathematical analysis of positions
  • Quantitative comparison between moves
  • Graphical visualization of game evolution
  • Prediction through neural networks
  • Database of positions with their S values


1.2 Program Philosophy
----------------------

The program is based on the idea that every chess position can be represented
as a unique number using the PRODUCT OF PRIME NUMBERS RAISED TO EXPONENTS
that represent pieces and squares.


1.3 Fundamental Concepts
------------------------

+-----------------------------------------------------------------------------+
¦ CONCEPT       ¦ EXPLANATION                                               ¦
+---------------+-------------------------------------------------------------¦
¦ S VALUE       ¦ Unique number representing the complete position.        ¦
¦ (S Value)     ¦ Calculated as the product of (Square Value ^             ¦
¦               ¦ Piece Value) for each piece on the board.                ¦
+---------------+-------------------------------------------------------------¦
¦ Log10(S)      ¦ Base-10 logarithm of the S Value. Allows working with    ¦
¦               ¦ more manageable numbers and visualizing trends.          ¦
+---------------+-------------------------------------------------------------¦
¦ VPo(k)        ¦ Position value at move k. This is the S Value at a       ¦
¦               ¦ specific moment.                                         ¦
+---------------+-------------------------------------------------------------¦
¦ D(k)          ¦ Difference between VPo(k) and VPo(k-1). Measures the     ¦
¦               ¦ change in value between consecutive moves.               ¦
+---------------+-------------------------------------------------------------¦
¦ R(k)          ¦ Ratio between VPo(k) and VPo(k-1). Measures the          ¦
¦               ¦ rate of change between moves.                            ¦
+---------------+-------------------------------------------------------------¦
¦ SQUARE        ¦ Each square has an associated prime number:              ¦
¦ MAPPING       ¦ a1=2, b1=3, c1=5, d1=7, e1=11, ... h8=311              ¦
+---------------+-------------------------------------------------------------¦
¦ PIECE VALUES  ¦ Each piece has an exponent value:                        ¦
¦               ¦ Pawn=1, Knight=5, Bishop=7, Rook=3, Queen=9, King=11    ¦
+-----------------------------------------------------------------------------+

5. GAME ANALYSIS
-------------------------------------------------------------------------------

5.1 What Does Analysis Do?
--------------------------

The analysis converts each position of the game into a GÖDEL VALUE (G) and
calculates derived metrics to understand the evolution of the game.


5.2 Analysis Process
--------------------

STEP BY STEP:
  1. Load a PGN (Load PGN)
  2. Click on "Analyze Game"
  3. The program processes each position of the game
  4. It calculates for each position:
       - S Value (exact) ? Product of (square^piece)
       - VPo(k) ? Position value
       - D(k) ? Difference from previous position
       - R(k) ? Ratio to previous position
  5. Saves positions in the database
  6. Shows a message with statistics

WHY DO IT?
  • To quantitatively understand the evolution of the game
  • To identify moves that drastically change the value
  • To compare different games or moves


5.3 Calculating the S Value
---------------------------

FORMULA:
  S = ?(Vs ^ Vp)

Where:
  • Vs = Square value (prime number assigned to each square)
  • Vp = Piece value (exponent)

PRACTICAL EXAMPLE:
  White pawn on e4:
    - Square e4 ? value 109
    - Piece P (white pawn) ? value 1
    - Contribution = 109^1 = 109

  Black knight on f6:
    - Square f6 ? value 199
    - Piece n (black knight) ? value 6
    - Contribution = 199^6

  The total S Value is the product of all these contributions.


5.4 Derived Metrics
-------------------

+-----------------------------------------------------------------------------+
¦ METRIC    ¦ FORMULA                   ¦ WHAT IT MEASURES                   ¦
+-----------+---------------------------+------------------------------------¦
¦ VPo(k)    ¦ S at move k               ¦ Absolute position value           ¦
¦ D(k)      ¦ VPo(k) - VPo(k-1)         ¦ Change between moves              ¦
¦ R(k)      ¦ VPo(k) / VPo(k-1)         ¦ Rate of change                    ¦
+----------------------------------------------------------------------------+

INTERPRETATION:
  • D(k) positive ? Position has improved
  • D(k) negative ? Position has worsened
  • R(k) > 1 ? Position has improved
  • R(k) < 1 ? Position has worsened


5.5 Analysis Example
--------------------

  Starting position: S = 2.45e+150
  After 1.e4: S = 3.12e+152
  D(1) = 3.10e+152 (significant improvement)
  R(1) = 127.3 (large improvement)

6.4 Interpreting Factors
------------------------

Example: 2^1 x 3^5 x 5^7 x 7^3 x 11^9

  • 2^1   ? White pawn on a1 (square 2, piece 1)
  • 3^5   ? White knight on b1 (square 3, piece 5)
  • 5^7   ? White bishop on c1 (square 5, piece 7)
  • 7^3   ? White rook on d1 (square 7, piece 3)
  • 11^9  ? White queen on e1 (square 11, piece 9)

The product of all these factors gives the exact S Value.

    - ...
    - King on e1: 283^11
  S = 23^1 × 29^1 × ... × 283^11 = 2.45e+150

WHY USE Log10(S)?
  • The S Value is astronomically large
  • Log10(S) compresses it to a manageable number
  • Facilitates visualization in graphs
  • Allows comparing positions on a logarithmic scale

+-----------------------------------------------------------------------------+

¦ Score                 ¦ Score in centipawns        ¦ 100 = 1 pawn advantage¦

WHAT IS A CENTIPAWN?
  • 1 centipawn = 1/100 of a pawn
  • Positive score = advantage for White
  • Negative score = advantage for Black

EXAMPLE SCORES:
  +45  = 0.45 pawn advantage for White
  -23  = 0.23 pawn advantage for Black
  +300 = Decisive advantage (won)

+-----------------------------------------------------------------------------+
¦ BUTTON              ¦ FUNCTION                 ¦ WHEN TO USE              ¦
+---------------------+--------------------------+--------------------------¦

¦                     ¦                          ¦ adding data             ¦

TRAINING PROCESS:
  1. Extract data: The network gets positions from the database
  2. Features: For each position, it extracts:
       - White/black material
       - Material balance
       - Piece count
       - Center control
       - Mobility
       - King safety
       - Pawn structure
  3. Normalize: Scales the features
  4. Train: The network adjusts its weights to minimize error
  5. Validate: Tests the model with unseen data

NEURAL NETWORK ARCHITECTURE:
  Input (features) ? Layer 1 (64 neurons) ? Dropout (20%)
  ? Layer 2 (32 neurons) ? Dropout (20%) ? Layer 3 (16 neurons)
  ? Output (1 neuron - position evaluation)


11.5.6 MOVE PREDICTIONS - THE MOST IMPORTANT SECTION!

TABLE STRUCTURE:

+-----------------------------------------------------------------------------+
¦ COLUMN       ¦ WHAT IS SHOWN             ¦ HOW IT IS CALCULATED          ¦
+--------------+---------------------------+-------------------------------¦
¦ #            ¦ Ranking order             ¦ Sorted by score               ¦
¦ Move (UCI)   ¦ Move in UCI format        ¦ e2e4 (source-destination)    ¦
¦ Move (SAN)   ¦ Move in algebraic notation¦ e4 (human-readable)           ¦
¦ S Value      ¦ Gödel value after move    ¦ S_after                       ¦
¦ Log10(S)     ¦ Logarithm of S Value      ¦ log10(S_after)                ¦
¦ NN Score     ¦ Network score             ¦ Evaluation of position        ¦
¦ Confidence   ¦ Confidence in prediction  ¦ NN_Score × 100               ¦
¦ SF Match     ¦ Matches Stockfish         ¦ ? Match / ? No match         ¦
+---------------------------------------------------------------------------+

INTERPRETATION OF EACH COLUMN:

# (Ranking)
  • WHAT IT IS: The ranking of moves according to the neural network
  • INTERPRETATION: Move #1 is the best according to the network
  • COLOR: Blue highlighted row for the best move

Move (UCI)
  • WHAT IT IS: Move in UCI (Universal Chess Interface) format
  • FORMAT: e2e4 (from e2 to e4)
  • WHY: This is the standard format for chess engines

Move (SAN)
  • WHAT IT IS: Move in standard algebraic notation
  • FORMAT: e4, Nf3, O-O
  • WHY: This is human-readable

S Value
  • WHAT IT IS: The Gödel value of the position after the move
  • INTERPRETATION:
      - Higher value = more control/material
      - Not directly better or worse
      - Depends on the phase of the game

Log10(S)
  • WHAT IT IS: Base-10 logarithm of the S Value
  • INTERPRETATION:
      - More manageable number
      - Facilitates comparison
      - Compressed version of the value

NN Score
  • WHAT IT IS: Neural network evaluation of the position
  • RANGE: 0.0 to 1.0 (normalized)
  • INTERPRETATION:
      - > 0.7  ? Good position (GREEN)
      - 0.5-0.7 ? Balanced position (YELLOW)
      - 0.3-0.5 ? Unfavorable position (ORANGE)
      - < 0.3  ? Bad position (RED)

Confidence
  • WHAT IT IS: NN Score expressed as a percentage
  • INTERPRETATION:
      - > 70% ? High confidence (GREEN)
      - 50-70% ? Medium confidence (YELLOW)
      - < 50% ? Low confidence (RED)

SF Match
  • WHAT IT IS: Indicates if the move matches Stockfish
  • INTERPRETATION:
      - ? Match ? Network matches Stockfish (good sign)
      - ? No match ? Network differs from Stockfish

11.8 FREQUENTLY ASKED QUESTIONS ABOUT THE NEURAL NETWORK

HOW MUCH DATA DOES IT NEED TO BE ACCURATE?
  • Minimum: 50 positions
  • Recommended: 1000+ positions
  • Ideal: 5000+ positions

WHAT DOES LOW ACCURACY MEAN?
  • There may not be enough data
  • The data may be noisy
  • The network may need more training

WHY DOESN'T THE NETWORK MATCH STOCKFISH?
  • The network may be right (Stockfish is not infallible)
  • The network may be wrong (needs more data)
  • Different evaluation criteria

HOW TO IMPROVE ACCURACY?
  • Analyze more games
  • Include games of different levels
  • Ensure data is of good quality

WHAT DOES SAFE MODE DO?
  • Applies logarithm to values
  • Prevents overflow from very large numbers
  • Facilitates visualization in graphs
